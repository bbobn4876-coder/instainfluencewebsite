# Loomera Leads — телеграм-бот

Поиск лидов из Telegram, а также ВКонтакте, 2ГИС и Instagram — прямо в чате.
Отдельная программа: веб-приложение, Netlify и база сайта ей не нужны.

Зависимостей нет. Нужен только **Python 3.10+**.

## Запуск за три шага

**1. Создайте бота**

В Telegram напишите [@BotFather](https://t.me/BotFather): `/newbot`, задайте имя
и username. Он пришлёт токен вида `8123456789:AAF...`.

**2. Положите токен в файл**

```bash
cp bot/.env.example bot/.env
# откройте bot/.env и впишите LEADS_BOT_TOKEN=8123456789:AAF...
```

**3. Запустите**

```bash
python3 bot/main.py
```

Должно появиться:

```
Бот @your_bot запущен. Ctrl-C — остановить.
  Telegram: готов
  ВКонтакте: нет ключа
  2ГИС / Карты: нет ключа
  Instagram: нет ключа
```

Теперь напишите боту `/start`. Пока он запущен — он отвечает; закроете
терминал — перестанет. Настройки и собранные сообщения остаются в
`bot/leads.sqlite3`.

## Интерфейс

Печатать ничего не нужно — всё кнопками. Напишите `/start`, и откроется меню:

```
        🔎 Найти лиды
  🏙 Город        🗂 Категория
  🔑 Слова        🔢 Сколько
  📡 Источники    💬 Чаты
      ❓ Как это работает
```

Меню живёт одним сообщением: нажатие не плодит новые, а перерисовывает текущее.
Город и слова можно выбрать из готовых вариантов или прислать свои — бот
попросит и подставит. Настройки у каждого чата свои.

Команд осталось три, на случай если удобнее ими: `/menu`, `/leads`, `/help`.

## Почему Telegram ничего не находит

Самое частое недоразумение. **Источник Telegram ищет только по сообщениям тех
групп, куда добавлен ваш бот.** Глобального поиска по Telegram у ботов нет —
такого API просто не существует, и всё, что его обещает, работает через чужой
личный аккаунт с риском его потерять.

Поэтому в пустой личке поиск всегда вернёт 0. Чтобы заработало:

1. Добавьте бота в рабочие чаты, где ищут подрядчиков.
2. @BotFather → `/mybots` → ваш бот → Bot Settings → Group Privacy → **Turn off**.
3. **Удалите и добавьте бота в чат заново** — без этого старая настройка
   остаётся в силе.

Кнопка **💬 Чаты** покажет, что бот реально видит: сколько сообщений получил из
каждого чата и сколько отложил как похожие на поиск подрядчика. Если напротив
чата «видел 0» — Group Privacy всё ещё включён.

Дальше он накапливает сообщения сам, поэтому сразу после подключения выдача
будет небогатой. Остальные три источника ищут вживую и от этого не зависят.

## Источники

**Telegram — без ключей.** Добавьте бота в рабочие чаты. Он запоминает
сообщения, похожие на поиск подрядчика («ищу смм», «нужен видеограф»,
«посоветуйте подрядчика»), и `/leads` ищет по ним. Обычную болтовню он не
хранит.

По умолчанию Telegram показывает боту в группах только команды. Чтобы он видел
сообщения целиком: @BotFather → `/mybots` → ваш бот → Bot Settings → Group
Privacy → **Turn off**, затем **заново добавьте бота в чат**.

Учтите: это чужая переписка. Добавляйте бота только в чаты, где вы вправе это
делать, и лучше скажите участникам.

**ВКонтакте** — `VK_SERVICE_TOKEN`. Официальное API: посты, где ищут
подрядчика, плюс группы местного бизнеса с заброшенной стеной.

**2ГИС** — `DGIS_API_KEY`. Каталог: компании с рейтингом и телефоном, но без
соцсетей.

**Instagram** — `HIKER_TOKEN`. Через HikerAPI. **Каждый профиль — платный
запрос**, поэтому `LEADS_IG_PROFILES` (по умолчанию 40) — это то, сколько
стоит один поиск.

**Авито здесь нет.** Открытого API у него для этого нет, а единственный путь —
обход их защиты от ботов. Это не реализовано и не будет.

Без ключей бот всё равно работает: Telegram ищет, остальные помечены «нет
ключа» и не запускаются. Ничего не выдумывается.

## Чтобы работал круглосуточно

На своей машине бот живёт, пока открыт терминал. Чтобы не следить за ним:

```bash
# Linux с systemd
sudo tee /etc/systemd/system/loomera-leads.service > /dev/null <<UNIT
[Service]
ExecStart=/usr/bin/python3 /путь/к/проекту/bot/main.py
WorkingDirectory=/путь/к/проекту/bot
Restart=always
User=$USER
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now loomera-leads
```

Подойдёт любой дешёвый VPS. Публичный адрес и вебхук не нужны: бот сам
опрашивает Telegram (long polling).

## Частое

Сначала запустите диагностику — она скажет, что бот видит:

```bash
python3 bot/main.py --check
```

**`CERTIFICATE_VERIFY_FAILED: self-signed certificate in certificate chain`**

Между вами и Telegram что-то пересобирает HTTPS: антивирус с проверкой трафика
(Kaspersky, ESET, Dr.Web), корпоративный прокси или VPN-клиент. Браузер его
корневой сертификат уже знает, а у Python своё хранилище. По порядку:

1. **macOS, свежий Python** — запустите установщик сертификатов рядом с самим
   Python: `/Applications/Python 3.x/Install Certificates.command`
2. **Обновите корневые сертификаты:** `python3 -m pip install --upgrade certifi`.
   Бот подхватит их сам.
3. **Антивирус или рабочая сеть** — экспортируйте их корневой сертификат в
   `.pem` и впишите путь в `bot/.env`:
   ```
   LEADS_CA_BUNDLE=/путь/к/corporate-root.pem
   ```
   В Windows он лежит в «Сертификаты → Доверенные корневые», экспорт
   «Base-64 encoded X.509 (.CER)», файл можно переименовать в `.pem`.
4. **Проще всего** — выключить проверку HTTPS в антивирусе или запустить бота
   из другой сети (мобильный интернет).

`LEADS_INSECURE=1` отключает проверку совсем. Это годится, чтобы убедиться, что
дело именно в сертификате, но жить так не стоит: тот, кто вклинился в
соединение, прочитает токен бота.

**«Нет токена»** — не создан `bot/.env` или в нём пустой `LEADS_BOT_TOKEN`.

**`Conflict: terminated by other getUpdates`** — тот же бот уже запущен где-то
ещё. Один токен — один процесс.

**Бот молчит в группе** — не выключен Group Privacy (см. выше) или он был
добавлен до того, как настройку сменили.

**Ничего не находит** — проверьте `/status`. Если у источников «нет ключа»,
ищет только Telegram, а ему нужно время, чтобы накопить сообщения.
